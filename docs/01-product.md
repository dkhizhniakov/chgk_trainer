# 01 — Продукт

## Цель

Дать игроку ЧГК один инструмент, чтобы:

1. **Играть** — отвечать на реальные вопросы турниров в условиях, близких к игре (60 секунд, пакеты целиком).
2. **Запоминать** — системно закреплять факты, которые всплывают в вопросах, через интервальное повторение.
3. **Расширять кругозор** — изучать базу знаний (люди, события, произведения…), связанную с вопросами.

## Роли

| Роль | Возможности |
|---|---|
| Гость | Просмотр лендинга, регистрация/вход |
| Игрок (`player`) | Тренировки, статистика, повторение, просмотр базы вопросов и базы знаний, личные заметки |
| Редактор (`editor`) | + создание/редактирование вопросов, турниров, сущностей базы знаний, связей |
| Администратор (`admin`) | + импорт, управление пользователями и ролями |

Роли реализуются группами Cognito (`editor`, `admin`); `player` — любой аутентифицированный пользователь.

## Функциональные области

### 1. База вопросов

- Турниры (пакеты) → туры → вопросы.
- Поля вопроса: текст, раздаточный материал (текст или изображение), ответ, зачёт, незачёт, комментарий, источники, авторы, теги/темы, сложность.
- Табличный просмотр (material-react-table): фильтры по турниру, дате, сложности, тегам, автору; сортировка; серверная пагинация.
- Карточка вопроса со связанными сущностями базы знаний.
- Ручное создание и редактирование (редактор).
- Импорт: db.chgk.info, файлы (см. [09 — Импорт](09-import.md)).

### 2. База знаний

- Сущности типов: `person`, `event`, `place`, `work` (произведение), `organization`, `concept`, `other`.
- Поля: название, алиасы, даты, краткое описание, список **фактов**, ссылки на источники (Википедия и т.п.), изображение.
- Связи: сущность ↔ сущность (например, «автор» → «произведение»), сущность ↔ вопрос.
- Факты — атомарные утверждения, которые можно добавлять в повторение.

### 3. Тренировки

Подробно — [10 — Тренировки и повторение](10-training.md).

| Режим | Описание |
|---|---|
| **Блиц на время** | Случайные вопросы по фильтрам, таймер 60 с (+ 10 с на запись, настраивается) |
| **Отыгрыш пакета** | Турнир целиком по порядку, с итоговым результатом и сравнением |
| **Повторение** | Ежедневная очередь карточек (вопросы и факты), алгоритм FSRS |
| **Изучение** | Навигация по базе знаний, переход от вопроса к сущностям и обратно |

### 4. Статистика

- Процент взятых вопросов в целом, по темам, по турнирам, по времени.
- История сессий.
- Прогресс повторения: карточек к повторению сегодня, выученных, «трудных».

## Ключевые пользовательские сценарии

1. *Как игрок*, я выбираю «Блиц», задаю фильтры (сложность, годы, темы), отвечаю на 12 вопросов на время и вижу результат.
2. *Как игрок*, после неудачного ответа я одним нажатием добавляю вопрос (или факт из связанной сущности) в повторение.
3. *Как игрок*, я каждый день открываю «Повторение» и прохожу очередь карточек.
4. *Как игрок*, я отыгрываю пакет турнира и сравниваю свой результат.
5. *Как редактор*, я импортирую турнир из db.chgk.info, проверяю его и связываю вопросы с сущностями.
6. *Как игрок*, из карточки вопроса я перехожу к персоне, читаю факты о ней и вижу другие вопросы про неё.

## Нефункциональные требования

- Работает локально без деплоя приложения (БД и Cognito — в AWS, dev-окружение).
- Мультиязычный интерфейс (i18n): базовый язык — русский, модульная архитектура для легкого добавления новых языков (en и др.); адаптивная вёрстка (desktop + mobile).
- Время ответа API p95 < 300 мс для типичных запросов.
- Стоимость прод-окружения при малой нагрузке — десятки USD в месяц.
- Уважение к лицензиям источников вопросов: хранение ссылок на источник и авторов.

## Глоссарий ЧГК

| Термин | Значение |
|---|---|
| Пакет / турнир | Набор вопросов, сыгранных на одном турнире |
| Тур | Часть пакета (обычно 12–15 вопросов) |
| Раздатка | Раздаточный материал к вопросу (текст или изображение) |
| Зачёт | Альтернативные ответы, которые засчитываются |
| Незачёт | Ответы, которые явно не засчитываются |
| Комментарий | Пояснение к ответу |
| Редактор пакета | Человек, отвечающий за пакет турнира |
| Взятие | Правильный ответ команды на вопрос |
