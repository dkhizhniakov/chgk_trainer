# ADR-0007: FSRS для интервального повторения

**Статус**: принято

## Контекст

Нужен алгоритм планирования повторений для вопросов и фактов. Варианты: SM-2 (классика Anki/SuperMemo), FSRS (современный, используется в Anki по умолчанию с 23.10).

## Решение

FSRS через библиотеку `github.com/open-spaced-repetition/go-fsrs` с параметрами по умолчанию и настраиваемой целевой вероятностью вспоминания. Сохраняем полный лог повторений.

## Последствия

- (+) Меньше повторений при той же запоминаемости по сравнению с SM-2.
- (+) Лог позволяет позже оптимизировать параметры под пользователя.
- (−) Состояние карточки сложнее (stability, difficulty и т.д.) — хранится в `userdata`.
