# ADR-0005: Локальная разработка против настоящего DynamoDB

**Статус**: принято

## Контекст

Требование: всё работает локально без деплоя, но база данных всегда DynamoDB. Альтернатива — DynamoDB Local в Docker — имеет отличия в поведении (лимиты, некоторые API, IAM) и требует отдельного наполнения данными.

## Решение

- Окружение Terraform `dev` создаёт в AWS только данные и сервисы: таблицы DynamoDB, Cognito user pool, S3 для медиа.
- Backend локально использует профиль AWS (`AWS_PROFILE=chgk-dev`) и префикс таблиц `chgk-dev`.
- Для изоляции разработчиков/тестов — суффиксы префикса (`chgk-dev-alice`, `chgk-test-<random>`).

## Последствия

- (+) Поведение БД, IAM и Cognito идентично продакшну.
- (+) Данные dev сохраняются между сессиями и доступны с любой машины.
- (−) Нужен интернет и активная AWS-сессия для разработки.
- (−) Небольшие расходы на dev (on-demand — центы при разработке).
- (−) Интеграционные тесты медленнее, чем с эмулятором.
