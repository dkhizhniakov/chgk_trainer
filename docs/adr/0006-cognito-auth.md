# ADR-0006: Аутентификация через Cognito

**Статус**: принято

## Контекст

Нужны личные данные (статистика, повторение) и роли (`editor`, `admin`). Писать собственную аутентификацию (хранение паролей, сброс, подтверждение email) нецелесообразно.

## Решение

- Amazon Cognito User Pool, вход по email + пароль (SRP), группы `editor`, `admin`.
- Frontend — Amplify Auth (только модуль auth), собственные формы на MUI.
- Backend — проверка access token по JWKS пула (`iss`, `client_id`, `token_use=access`, `exp`), роли из `cognito:groups`.
- Локально используется dev user pool; для оффлайн-отладки — `AUTH_DEV_BYPASS` только при `APP_ENV=local`.

## Последствия

- (+) Регистрация, подтверждение, сброс пароля, MFA, социальные логины — из коробки.
- (+) Backend stateless, без хранения сессий.
- (−) Привязка к AWS; миграция пользователей из Cognito нетривиальна (пароли не экспортируются).
