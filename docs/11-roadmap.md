# 11 — Roadmap

## Этап 0 — Фундамент

- [ ] Монорепозиторий: `api/`, `backend/`, `frontend/`, `infra/`, `scripts/`
- [ ] Terraform: `bootstrap`, модули `dynamodb`, `cognito`, `media`; окружение `dev`
- [ ] OpenAPI-скелет (`/health`, `/me`) + генерация Go/TS
- [ ] Backend: конфиг, логирование, middleware, проверка JWT, `GET /me`
- [ ] Frontend: Vite + MUI-тема, роутер, Amplify Auth (вход/регистрация), layout
- [ ] ESLint, Prettier, golangci-lint; скрипты `dev.ps1`, `infra.ps1`, `lint.ps1`
- [ ] CI: линт и тесты на pull request

**Результат**: локально можно зарегистрироваться, войти и увидеть свой профиль, данные — в DynamoDB.

## Этап 1 — База вопросов

- [ ] CRUD турниров и вопросов, индекс-элементы (теги, авторы, годы)
- [ ] Импорт: db.chgk.info, 4s, JSON (CLI + админ-страница)
- [ ] Таблицы турниров и вопросов (material-react-table, серверная пагинация, фильтры в URL)
- [ ] Карточка вопроса, редактор вопроса, загрузка раздаток в S3

## Этап 2 — Тренировки

- [ ] Сессии, выбор случайных вопросов, исключение виденных
- [ ] Блиц на время: фазы, таймер, горячие клавиши
- [ ] Проверка ответов (`answercheck`) + самопроверка
- [ ] Отыгрыш пакета с сохранением прогресса
- [ ] Агрегаты статистики, дашборд, история сессий

## Этап 3 — Продакшн

- [ ] Terraform: `network`, `ecr`, `ecs-api`, `frontend`, `monitoring`, (опц.) `dns`; окружение `prod`
- [ ] Dockerfile, GitHub Actions с OIDC: сборка, пуш в ECR, `terraform apply`, деплой SPA
- [ ] Алерты, бэкапы (PITR), проверка восстановления

## Этап 4 — База знаний

- [ ] Сущности, алиасы, факты, связи
- [ ] Автодополнение, список по типам, карточка сущности
- [ ] Привязка вопросов к сущностям (из карточки вопроса и из карточки сущности)
- [ ] Визуализация связей (граф)

## Этап 5 — Повторение

- [ ] Карточки вопросов и фактов, FSRS, очередь, дневные лимиты
- [ ] Автодобавление невзятых вопросов
- [ ] Статистика повторения
